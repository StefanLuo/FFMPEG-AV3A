# adm_render：AVS M6657参考代码
ADM_Render根据N2989“信息技术虚拟现实内容高效编码 第3部分：音频”的要求，定义渲染元数据编码技术；及N3066 “AVS‘虚拟现实内容表达第三部分：音频’ 技术方案征集书”的要求，于虚拟现实设备及其它3D音频回放系统中提供音频渲染技术：支持根据用户不同的回放环境（例如耳机，扬声器位置、数量、混响等），进行扬声器或耳机信号输出映射，并保持一致的用户听音沉浸效果；支持用户与场景的交互（基于时间和用户行为）；支持多通道的上混、下混等音频渲染方式。本提案提出了开放兼容ADM的渲染器架构与实现方案。

## 技术架构设计原则
除响应N2989和N3066的技术要求，标准化渲染器的开发对于新一代音频系统的真正普及应用非常重要。意味着，对于在广播系统框架内开发的系统的内容制作、质量评估和验证提出了至关重要的技术要求。
本提案设计的音频渲染器，用于直接解析ITU-R BS.2076 ADM元数据，我们认为，在音频评估、制作和监听期间，为ADM元数据解析提供一个开放的参考渲染器，将有利于音频内容生态系统的整体健康。
本渲染器须应用和处理此接口中提供的元数据和相关音频数据，体现以下渲染原则：
•	正确处理响度相关的元数据，保持目标响度
•	保留艺术意图，如正确应用传输的上混、下混矩阵
•	适当地呈现对象的空间属性（位置、空间范围等）
•	正确处理漫反射、发散角方位距离和排除扇区元数据
•	正确处理高优先级的音频对象


## 安装

### 依赖库

  - compiler with C++11 support
  - Boost header libraries (version 1.57 or later)
      - Boost.Optional
      - Boost.Variant
  - CMake build system (version 3.5 or later)

### 独立安装

clone项目仓库到本地然后：

mkdir build && cd build
cmake ..
make
make install
